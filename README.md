# React + TypeScript + MUI App

## Stack
- React 19.2
- TypeScript 6.0
- MUI (Material UI) v7
- Vite 8
- Docker + Docker Compose

## Requirements
- Docker
- Docker Compose

That's it! No Node.js required on your machine.

## Getting Started

```bash
docker compose up
```

Then open: http://localhost:5173

## Notes
- First run installs dependencies (~1-2 min). Subsequent runs are instant.
- Hot reloading is enabled — file changes reflect immediately in the browser.
- `node_modules` lives inside the container, not on your host machine.
